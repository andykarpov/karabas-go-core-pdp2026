# Ядро PDP-11/70 для Karabas Go

[English version](README.md)

PDP-11/70 — мини-ЭВМ DEC 1975 года, старшая модель семейства PDP-11 (в СССР это семейство
повторяли СМ ЭВМ, ДВК, «Электроника-60» и многие другие). Это ядро превращает плату Karabas в такую машину: процессор
с плавающей точкой и диспетчером памяти, диски RK05, RL02 и RP06, перфолента, часы и пульт с
лампочками. На дисках — операционная система RT-11 с языками и играми.

Это форк [pdp2026](https://github.com/tsybulin/karabas-go-core-pdp2026) Павла Цыбулина. Процессор —
pdp2011 Sytse van Slooten. Экраном служит встроенный терминал VT100. Это второй PDP-11 внутри той
же ПЛИС: по-настоящему к PDP-11/70 подключали отдельный терминал, и здесь он устроен так же.

| Плата | Файл ядра | Видео |
|---|---|---|
| Karabas Go | `src/pdp2026.kg` (один файл для всех плат) | VGA 640 x 480 |
| Karabas Mini | | HDMI / DVI 640 x 480 |
| Karabas Mini G | | HDMI / DVI 640 x 480 |

Состояние: проверено на Mini G (монитор, bootmon, консоль на терминале и на USB, OSD). Сборки для
Go и Mini на платах ещё не запускались.

## Что понадобится

- Плата Karabas и прошивка v26111914 или новее.
- SD-карта в обычном слоте (SD1) с файлом ядра.
- **Вторая SD-карта** для слота SD2 (слот ПЛИС): на ней диски PDP-11. Подойдёт любая: готовые
  диски занимают первые ~100 MB. Её содержимое будет стёрто.
- USB- или PS/2-клавиатура.
- ПК с Linux (или macOS) для записи дисков на вторую карту.

## Шаг 1. Диски на вторую SD-карту

Диски PDP-11 лежат на карте не файлами, а «сырыми» блоками по фиксированным адресам, как на
настоящем жёстком диске. Записывает их утилита `sd-store` из `disks/tools`.

1. Соберите утилиты (нужен `gcc` и `make`):

   ```
   cd disks/tools
   make
   ```

2. Распакуйте образы дисков:

   ```
   cd ..
   for f in *.tar.xz; do tar xJf "$f"; done
   ```

   Появятся файлы `B0-RK0.dsk`, `B0-RK1.dsk` и другие: `B<банк>-<тип><номер>.dsk`.

3. Вставьте вторую карту в картридер и найдите её имя устройства: `lsblk` до и после того, как
   вставили карту, например `/dev/sdc`. **Ошибётесь с устройством — сотрёте другой диск.**
   Если система смонтировала разделы карты, отмонтируйте их: `sudo umount /dev/sdc?*`.

4. Запишите диски (из каталога `disks`, где лежат `.dsk`). Параметры: устройство, тип диска,
   номер диска, банк:

   ```
   sudo tools/sd-store /dev/sdc RK 0 0
   sudo tools/sd-store /dev/sdc RK 1 0
   sudo tools/sd-store /dev/sdc RK 3 0
   sudo tools/sd-store /dev/sdc RK 4 0
   sudo tools/sd-store /dev/sdc RK 5 0
   sudo tools/sd-store /dev/sdc RL 0 0
   sudo tools/sd-store /dev/sdc RL 2 0
   sync
   ```

   Без пятого параметра `sd-store` берёт файл `B<банк>-<тип><номер>.dsk`. Свой образ можно указать
   пятым параметром: `sudo tools/sd-store /dev/sdc RK 2 0 mydisk.dsk`.

5. Вставьте карту в слот SD2 платы.

Что на готовых дисках:

| Диск | Содержимое |
| :--: | --- |
| RK0 | RT-11 v05.07, загрузочный диск (обязателен) |
| RK1 | примеры и тесты на ассемблере MACRO-11 |
| RK3 | FORTRAN-11 |
| RK4 | игры для PDP-11 и ДВК |
| RK5 | системные тесты в образах перфолент |
| RL0 | FIG-FORTH для RT-11 и без ОС |
| RL2 | исходники RT-11 |

Для начала хватит одного RK0. Подходят и другие simh-совместимые образы RK05, RL02 и RP06 (тип
`DB` у `sd-store`, лучше с опцией autozap). Прочитать диск с карты обратно в файл: `sd-extract`
с теми же параметрами.

### Банки

Банк — это полный набор дисков: 8 RK05, 4 RL02, 8 RP06 и перфолента, 2 GB карты. В OSD (**Menu+Esc** >
**Disks**) для каждого типа выбирается банк 0..3, так что на одной карте можно держать 4 набора и
переключать их без перезаписи.

### Одна карта для всего

Чтобы на той же карте держать обычные файлы:

1. Разбейте карту на разделы, первый раздел нужного размера.
2. В OSD (**Disks** > **SD2 offset**) поставьте смещение больше размера этого раздела.
3. При записи `sd-store` берите банк со сдвигом: каждые 8 GB смещения прибавляют к номеру банка 4.

| SD2 offset | Банки для `sd-store` |
| :--: | :--: |
| 0 | 0 .. 3 |
| 8 GB | 4 .. 7 |
| 16 GB | 8 .. 11 |
| ... | ... |
| 56 GB | 28 .. 31 |

Пример: карта 16 GB, первый раздел 7,9 GB, SD2 offset 8 GB, банки 4..7.

## Шаг 2. Первый запуск

Скопируйте `src/pdp2026.kg` в корень карты SD1 и выберите **PDP-11/70** в меню ядер. На экране
появятся:

```
PIP.11.70.CONS

000106 000000 000000 000000
$
```

Это пульт M9312: числа — содержимое регистров (в восьмеричной системе, как всё в PDP-11), `$` —
приглашение пульта.

## Пульт M9312

Пульт понимает команды из двух символов, сразу после них — восьмеричное число и Enter. Ввод
регистра не важен.

| Команда | Что делает |
| --- | --- |
| `DK` Enter | загрузиться с RK0 (`DK1` — с RK1 и т. д.) |
| `DL` Enter | загрузиться с RL0 |
| `DB` Enter | загрузиться с RP06 |
| `L 1000` Enter | запомнить адрес 1000 |
| `E ` (E и пробел) | показать слово по запомненному адресу; следующий `E ` — следующее слово |
| `D 123456` Enter | записать 123456 по запомненному адресу; следующий `D` — в следующее слово |
| `S` Enter | сброс и запуск с запомненного адреса |

Слово PDP-11 16-битное: числа до 177777 (лишние старшие разряды отбрасываются), адреса слов
чётные. Пример:

```
$L 1000
$D 123456
$L 1000
$E 001000 123456
```

Символы читаются парами: если нажать лишний Enter перед командой, пара сдвинется, и пульт ответит
новым `$`. Просто введите команду ещё раз.

## Шаг 3. RT-11

Введите `DK` и Enter. Загрузится RT-11: после её заставки появится точка `.` — приглашение ОС.

Первые команды:

| Команда | Что делает |
| --- | --- |
| `DIR` | список файлов на системном диске |
| `DIR RK4:` | файлы на диске RK4 |
| `TYPE файл` | показать текстовый файл |
| `RUN программа` | запустить программу (`.SAV`) |
| `COPY откуда куда` | копировать файл |
| `@файл` | выполнить командный файл (`.COM`) |
| `SHOW` | конфигурация системы |

Имена устройств: `DK:` — диск, с которого загрузились, `RK0:`..`RK7:` — диски RK05, `DL0:`..`DL3:` —
RL02, `DB0:` — RP06, `PC:` — перфолента. Команды можно сокращать (`DIR` = `DIRECTORY`).

Тетрис: запишите RK0, RK1 и RK4, загрузитесь и введите `@TETRIS`.

PDP-11 нельзя «выключить»: RT-11 пишет на диск сразу, так что достаточно дождаться конца работы
программы. **F12** сбрасывает машину и возвращает в пульт, **F11** (Halt / Run) останавливает
программу, выходит в пульт и, если нажать ещё раз, продолжает её с того же места.

## Перфолента

Перфолента — это отдельная область карты: RT-11 «пробивает» на ней ленту (`PC:`), а абсолютный
загрузчик пульта её читает. Так загружаются программы и тесты без ОС. Шаги 1..4 нужны только при
смене ленты.

1. Загрузите RT-11.
2. Список лент:

   ```
   DIR RK5:
   ```

3. Запишите ленту, например *BASIC.TAP*:

   ```
   COPY RK5:BASIC.TAP PC:
   ```

4. Перезапустите ядро: Ctrl+Alt+Backspace и снова PDP-11/70 в меню ядер.
5. В пульте запустите абсолютный загрузчик ленты по адресу 157500:

   ```
   L 157500
   S
   ```

### Тесты

**Tape bank** (OSD > Disks) выбирает одну из 4 лент. Для тестов полезно включить **Front panel**
(лампочки пульта поверх картинки). После загрузки тесты сами не запускаются, большинство стартует
с адреса 200.

1. Запишите тест в банк 1 и перезапустите ядро (Ctrl+Alt+Backspace, PDP-11/70 в меню ядер):

   ```
   COPY RK5:CKBAB0.TAP PC:
   ```

2. Выберите **Tape bank** = Bank 1 и загрузите тест (`L 157500`, `S`). После загрузки машина
   остановится, зелёная лампочка погаснет.
3. Сбросьте машину (**F12**) и запустите тест:

   ```
   L 200
   S
   ```

Во время теста мигают 3 лампочки пульта, каждый проход отмечается звонком. Тест бесконечен,
выход — **F12**.

## Монитор bootmon

Второй загрузчик с меню, лежит в памяти по адресу 140000:

```
L 140000
S
```

Появится `PDP-11 MONITOR V1.0` и приглашение `BOOT>`. Команды: `BOOT` (загрузка с RK, RL или RP),
`HALT`, `TEST`, `DIAG`, `LIGHTS`, `HELP`.

## Консоль на ПК

Пункт **Console** = **USB serial** переключает консоль PDP-11 со встроенного терминала на порт ядра
платы (115200 8N1). Это второй USB-последовательный порт:
`/dev/serial/by-id/usb-Karabas_Go_<серийник>-if02` в Linux, `/dev/cu.usbmodem<серийник>3` в macOS,
COM-порт «Karabas core serial» в Windows. Подойдёт любой терминал, например:

```
picocom -b 115200 /dev/serial/by-id/usb-Karabas_Go_<серийник>-if02
```

Экран платы при этом остаётся с терминалом, но к PDP-11 он не подключён.

## OSD

**Menu+Esc** («Menu» — клавиша Windows):

- **Reset** (**F12**): сброс машины;
- **Halt / Run** (**F11**): кнопка HALT / CONT пульта (см. выше);
- **Console**: Terminal (встроенный VT100) или USB serial (порт ядра на ПК);
- **Colour**: цвет текста: Amber, Green или White;
- **Sound**: звонок терминала (HDMI и звуковой выход);
- **Front panel**: лампочки пульта поверх картинки (видны и без карты в SD2);
- **Slow CPU**: замедленный процессор;
- **Disks**: **SD2 offset** и банки **RK**, **RL**, **RP**, **Tape**.

Ctrl+Alt+Backspace возвращает в меню ядер.

## Отличия от ядра автора

- MCU link v2 и модули karabas-go-modules: новое OSD, загрузка ROM, часы, порт ядра; сборка через
  `src/Makefile`;
- исправления терминала из [karabas-go-core-vt100](https://github.com/andykarpov/karabas-go-core-vt100):
  делитель приёмника kl11 (на 115200 текст портился), XON / XOFF в ядре (при прокрутке ничего не
  теряется);
- консоль PDP-11 на порту ядра USB (пункт **Console**);
- команда `RESET` больше не обрывает символ на линии консоли (баннер bootmon выводился мусором);
- звонок терминала на HDMI и на звуковом выходе.

## Сборка

ISE 14.7: `cd src && make minig` (или `go`, `mini`), `make minig-report`. Модули берутся из
подмодуля `modules` (karabas-go-modules): `git submodule update --init`. `src/make_core.py` —
ссылка на karabas-go-tools рядом с этим репозиторием. Топы Go и Mini делаются из топа Mini G:
`python3 src/tools/mktops.py`. Тестбенч UART консоли: `src/sim/tb_wbc_uart_reset.v` (iverilog).

## Лицензия

У ядра автора файла лицензии нет. Исходники pdp2011 / VT100 (`src/rtl/vt100`) принадлежат Sytse van
Slooten: только личное некоммерческое использование, их заголовки не меняются.
